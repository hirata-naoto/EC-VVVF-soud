# 回路図 / Schematic

このドキュメントでは `src/ec-vvvf-sound.py` を動作させるための配線を示します。

## 使用部品

| 部品 | 説明 |
|------|------|
| Raspberry Pi Pico (RP2040) | メインボード |
| MAX98357A モジュール | I2S DAC + アンプ内蔵モジュール |
| スピーカー (4〜8Ω) | 音声出力 |
| 可変抵抗 (10kΩ 推奨) | マスコン相当の操作入力 |

> 他の I2S DAC モジュール（PCM5102A 等）も同様のピン接続で利用できます。  
> その際は各モジュールのデータシートを参照してください。

---

## ピン接続一覧

### RP2040 ↔ MAX98357A（I2S 出力）

| RP2040 ピン | MAX98357A ピン | 説明 |
|-------------|---------------|------|
| GP2 (Pin 4) | LRC / LRCLK | 左右クロック（LRCK） |
| GP3 (Pin 5) | BCLK | ビットクロック |
| GP4 (Pin 6) | DIN | シリアルデータ |
| 3V3 (Pin 36) | VIN | 電源（3.3V） |
| GND | GND | グランド |

> MAX98357A の SD モード端子（SD/MODE）はフロート（未接続）または 100kΩ でプルアップしてください。

### RP2040 ↔ 可変抵抗（マスコン入力）

| RP2040 ピン | 可変抵抗端子 | 説明 |
|-------------|-------------|------|
| 3V3 (Pin 36) | 一方の端子 | 電源側 |
| GP26 (Pin 31) | ワイパー（中央端子）| ADC 入力 |
| GND | もう一方の端子 | グランド側 |

### MAX98357A ↔ スピーカー

| MAX98357A ピン | スピーカー端子 | 説明 |
|---------------|--------------|------|
| OUT+ | ＋ | スピーカー正極 |
| OUT- | − | スピーカー負極 |

## 接続図（ASCII）

```
  Raspberry Pi Pico (RP2040)
  ┌──────────────────────────┐
  │                          │
  │  GP2 (Pin 4) ────────────┼──── LRC   ┐
  │  GP3 (Pin 5) ────────────┼──── BCLK  │ MAX98357A
  │  GP4 (Pin 6) ────────────┼──── DIN   │
  │  3V3 (Pin 36)────────────┼──── VIN   │
  │  GND         ────────────┼──── GND   ┘
  │                          │             OUT+ ──── スピーカー (+)
  │                          │             OUT- ──── スピーカー (-)
  │                          │
  │  3V3 (Pin 36)────────────┼──── 可変抵抗 端子A
  │  GP26 (Pin 31)───────────┼──── 可変抵抗 ワイパー（中央）
  │  GND         ────────────┼──── 可変抵抗 端子B
  │                          │
  └──────────────────────────┘
```

## 動作電圧・電流の目安

| 項目 | 値 |
|------|-----|
| RP2040 動作電圧 | 3.3V（USB 給電時は 5V → 内蔵レギュレータで 3.3V に変換） |
| MAX98357A 動作電圧 | 2.5〜5.5V（3.3V 給電で動作） |
| MAX98357A 出力電力 | 3.3V 給電 / 4Ω スピーカー時: 最大約 0.9W |
| 可変抵抗推奨値 | 10kΩ（B カーブ） |

---

## 注意事項

- RP2040 の GPIO は 3.3V 系です。5V を直接入力しないでください。
- スピーカーのインピーダンスが低すぎると MAX98357A が過熱する場合があります。4Ω 以上を推奨します。
- 可変抵抗のワイパー出力は 3.3V 以下になるよう構成してください。
- 音量や音質はスピーカーの特性に大きく依存します。
