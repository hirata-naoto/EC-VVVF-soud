# EC-VVVF-soud

Seeed XIAO ESP32C5 上で EC の VVVF インバータ風サウンドを生成するための MicroPython スクリプトです。  
I2S オーディオ出力を使って PWM ベースの音を出し、ADC 入力でマスコン相当の操作量を読み取って周波数を変化させます。

## 概要

このリポジトリには、`src/ec-vvvf-sound.py` という 1 本のメインスクリプトが含まれています。  
スクリプトは Seeed XIAO ESP32C5 上で次の処理を繰り返し実行します。

- ADC で操作入力を読む
- 入力値から信号波周波数を決める
- 信号波周波数に応じてキャリア周波数を切り替える
- サイン波と三角波を比較して SPWM 風の波形を生成する
- I2S へオーディオデータを送る

停止中は無音、力行時は周波数が上昇し、惰行時はその時点の周波数を維持する構成になっています。

## 主な仕様

- 実装言語: MicroPython
- 対象ハードウェア: Seeed XIAO ESP32C5
- オーディオ出力: I2S
- サンプルレート: 22050 Hz
- 出力フォーマット: 16bit / モノラル
- 波形生成方式: サイン波と三角波の比較による SPWM 風生成

## 入出力

### I2S 出力

スクリプトでは以下のピン割り当てで I2S を初期化しています。

| XIAO ピン | GPIO 番号 | I2S 信号 |
|-----------|-----------|---------|
| D8        | GPIO8     | BCLK    |
| D1        | GPIO0     | LRCK    |
| D6        | GPIO11    | DIN     |

実際に使用する DAC やアンプに合わせて、配線と対応ピンを確認してください。

### ADC 入力

| XIAO ピン | GPIO 番号 | 用途 |
|-----------|-----------|------|
| D0        | GPIO1     | マスコン ADC 入力 |

この入力値をマスコン相当の操作量として扱い、加速・惰行・停止方向の制御に利用しています。

## 動作の考え方

### 1. 操作入力の判定

ADC 値には簡易ローパスフィルタがかけられており、急な揺れやチャタリングを抑えています。  
そのうえで、入力値をおおまかに次の 3 状態に分けています。

- 低い値: 停止側として扱い、目標周波数を 0 Hz にする
- 高い値: 力行側として扱い、入力に応じて周波数を上げる
- 中間値: 惰行として扱い、現在の周波数を維持する

### 2. 信号波周波数の変化

現在の周波数は、目標値へ一気に飛ばさず、少しずつ追従するようにしています。  
これにより急変による不自然さを抑えています。

### 3. キャリア周波数の切り替え

信号波周波数に応じてキャリア周波数の決め方を変えています。

- 低周波域: 非同期寄りの動作
- 中低速域: 9 パルス相当
- 中高速域: 5 パルス相当
- 高速域: 最低でも 3 パルス相当を維持

また、キャリア周波数も急に変えず、なめらかに追従させています。

### 4. 音声バッファ生成

あらかじめ作成したサイン波テーブルを使って信号波を取り出し、三角波と比較して HIGH / LOW のサンプル値を作っています。  
これをオーディオバッファに詰めて I2S へ送ることで、VVVF 風の音を出力します。

## 使い方

1. Seeed XIAO ESP32C5 で MicroPython が動作する状態を用意します。
2. `src/ec-vvvf-sound.py` をボードへ配置します。
3. I2S 出力先となるオーディオ回路を接続します（D8/D1/D6 ピン）。
4. D0 (GPIO1) に操作用の可変入力を接続します。
5. スクリプトを実行し、入力値に応じて音の変化を確認します。

## 注意事項

- このリポジトリの配線図・回路図は [`docs/schematic.md`](docs/schematic.md) を参照してください。
- 使用する MicroPython のビルドによっては `I2S` の実装差異がある可能性があります。
- 音量や波形の性質は、接続先の DAC・アンプ・スピーカー構成にも影響されます。
- 閾値、周波数、出力レベルは `src/ec-vvvf-sound.py` 内で調整できます。
- XIAO ESP32C5 の GPIO は 3.3V 系です。5V を直接入力しないでください。

## 補足

現在の実装は、単一スクリプトで VVVF 風サウンド生成の基本動作をまとめた構成です。  
今後、車種ごとの音作り、設定値の外出し、複数モード切り替えなどを追加しやすい土台としても利用できます。
